# 파일 변환기 — 수동 테스트 체크리스트 (상시용)

`WINDOWS_TEST_GUIDE.md`는 **릴리스마다 새로 쓰는 문서**(그 버전에서 새로
생기거나 고친 기능만 골라 안내)이고, 이 문서는 그와 별개로 **모든 변환
경로를 언제든 훑어볼 수 있는 상시 체크리스트**다 — 회귀 테스트(오래된
기능이 최근 변경으로 깨지지 않았는지)나 정기 점검용으로 쓴다.

이 체크리스트는 `docs/07_test_plan.md`의 "자동 테스트가 못 잡는 것"
표와 짝을 이룬다 — 자동 유닛 테스트로 구조적으로 검증 불가능한 항목
(실제 한글/한워드/Word 뷰어 렌더링, 실제 설치·제거, 완전히 클린한
Windows 등)이 이 문서의 핵심이다. 자동 테스트로 이미 충분히 검증되는
세부 사항(예: 정렬 값이 JSON에 정확히 반영되는지)까지 여기서 다시 손으로
확인할 필요는 없다.

## 준비물

- `testing/samples/` 폴더의 샘플 파일(아래 표). HWPX·영상·이미지
  샘플은 저장소에 없다 — 앱으로 DOCX/PDF를 HWPX로 먼저 변환해 그 결과를
  다시 테스트에 쓰거나, 본인이 가진 실제 파일을 사용한다.
- 결과를 눈으로 확인하려면 **한글(HWP) 프로그램**과 **MS Word**(또는
  호환 뷰어)가 필요하다 — 이게 이 체크리스트의 가장 중요한 존재 이유다
  (Mac 개발 환경에는 둘 다 없음).
- 최신 릴리스 설치 파일: [GitHub Releases](https://github.com/jh3779/file-converter/releases)

| 파일 | 용도 |
|---|---|
| `04_한글테스트_DOCX에서HWP로.docx` | 긴 문단·번호 목록·불릿·표·한자 포함 — DOCX→HWP/HWPX 테스트용 |
| `05_한글테스트_엑셀시트.xlsx` | 날짜·소수 표시 형식, 시트 2개 — XLSX→CSV 테스트용 |
| `01_한글테스트.docx` | 드문 한글 자모·한자·표 포함 — DOCX→PDF/HWPX 테스트용 |
| `02_한글테스트.pptx` | PPTX→PDF 테스트용 |
| `03_한글테스트_PDF에서시작.pdf` | PDF→DOCX/HWP/HWPX/PPTX 테스트용 |
| `06_한글테스트_디자인서식.docx` | 셀 음영 있는 표(병합은 없음)·로고 이미지·머리글/꼬리글·페이지 나눔 등 서식이 여러 개 섞인 실사용 계약서 양식 — 순수 텍스트 샘플(01~05)로는 못 잡는 "디자인이 있는 문서" 회귀용(2026-08 Windows 실기기 테스트 중 추가) |

## 1. 설치·제거 (릴리스당 최소 1회)

- [ ] SmartScreen 차단 화면 → "추가 정보" → 실행까지 정상 진행
- [ ] 설치 모드 선택 화면에서 "나만 사용하도록 설치"(기본값) 선택 시
      관리자 권한(UAC) 없이 설치 완료
- [ ] 설치 마법사·앱 UI 언어가 한국어(시스템 언어 기준)로 나옴
- [ ] 바탕화면/시작 메뉴 바로가기 생성 및 정상 실행
- [ ] 프로그램 제거(제어판 → 프로그램 제거) 후 설치 폴더가 깨끗이 지워짐
- [ ] (완전히 클린한 Windows에서 여유가 있다면) 별도 VC++ 런타임 설치
      없이 앱이 정상 실행되는지 — CI 러너는 이미 런타임이 있어 이 경우를
      못 잡음

## 2. 문서 변환 — 결과를 실제 프로그램으로 열어 확인

각 항목은 "자동 테스트는 JSON/구조 레벨까지만 확인했고, 실제 렌더링은
아직 아무도 안 봤다"는 뜻이다.

### 2-1. DOCX → HWP / HWPX (`04_한글테스트_DOCX에서HWP로.docx`)

한글(HWP) 프로그램에서 결과 파일(.hwp, .hwpx 둘 다)을 열어 확인:

- [ ] 표가 실제 칸·테두리가 있는 진짜 표로 보임(텍스트로 뭉개지지 않음)
- [ ] 표 안 병합된 셀(가로/세로)이 실제로 합쳐진 모양으로 보임
- [ ] 표 안 내용이 각 칸에 빠짐없이 들어가 있음
- [ ] 표 헤더 행("이름"·"부서")이 가운데 정렬, "비고" 열이 오른쪽 정렬로
      보임(표 셀 안 정렬 보존, DEC-053)
- [ ] "확인 필요" 셀이 굵게+빨간색으로 보임(표 셀 안 문자 서식 보존, DEC-051)
- [ ] 긴 문단이 여러 줄로 자연스럽게 줄바꿈됨(겹치거나 깨지지 않음)
- [ ] 번호 목록·불릿이 그대로 보임
- [ ] 문단 정렬(가운데/오른쪽 등 원본에 지정된 것)이 반영됨
- [ ] 굵게/기울임/밑줄/글자크기/색상 서식이 반영됨
- [ ] 뷁·밟·닳 등 드문 글자, 大韓民國 등 한자가 정상적으로 보임
- [ ] .hwpx가 .hwp와 사실상 동일하게 보임(같은 원본에서 나왔으니 서식·
      구조가 대칭이어야 함 — DEC-049)

### 2-1b. DOCX → HWP / HWPX, 디자인 요소가 섞인 문서 (`06_한글테스트_디자인서식.docx`)

01~05는 순수 텍스트·표 위주라, 실사용 문서에 흔한 음영·이미지·머리글/꼬리글이
섞였을 때도 문서 전체가 안 깨지는지는 따로 확인이 필요하다. 결과 HWP/HWPX를
한글 프로그램으로 열어 확인:

- [ ] 표 내용·문자 서식(헤더 행 굵게, "비고" 열 빨간 글자 등)은 정상 반영됨(DEC-051 범위)
- [ ] 표 헤더 행 파란 음영·짝수 행 줄무늬 음영은 **범위 밖이라 안 보이는 게 정상** —
      음영 없이도 표 구조·셀 내용 자체는 깨지지 않는지만 확인
- [ ] 로고 이미지는 **범위 밖이라 빠지는 게 정상** — 이미지가 빠져도 나머지
      문단·표가 정상적으로 이어지는지(이미지 자리 때문에 뒤 내용이 밀리거나
      깨지지 않는지) 확인
- [ ] 머리글("ACME 주식회사 — 대외비")·꼬리글 텍스트는 범위 밖이라 빠질 수
      있음(정상) — 본문 텍스트에 섞여 들어가거나 중복되지 않는지만 확인
- [ ] 페이지 나눔은 **`docx_to_blocks`가 애초에 안 읽는 필드라 범위 밖** —
      "서명란"이 앞 내용과 이어져 한 페이지에 나와도 정상(반영되면 오히려
      의외이니 알려줄 것)

### 2-2. PDF → HWP / HWPX (`03_한글테스트_PDF에서시작.pdf`)

- [ ] 여러 페이지가 실제로 페이지 구분되어 나뉨(한 페이지로 뭉개지지 않음)
- [ ] 텍스트 내용이 원본 순서대로 보존됨

### 2-3. HWP / HWPX → DOCX

앱으로 임의의 실제 .hwp/.hwpx 파일(본인이 가진 것 권장 — 표·서식이
있는 실제 업무 문서일수록 좋음, 머리말/꼬리말/글상자가 있는 문서면
아래 항목까지 확인 가능)을 DOCX로 변환 후 Word/한글에서 확인:

- [ ] 문단·표 내용이 유지됨
- [ ] 굵게/기울임/밑줄/글자크기/색상 서식이 반영됨(문단·표 셀 안 둘 다 —
      DEC-027/038·DEC-051)
- [ ] 표 병합이 유지됨
- [ ] 표 셀 안 정렬(가운데/오른쪽 등)이 반영됨(DEC-053)
- [ ] 머리말·꼬리말·각주·미주·글상자 안 텍스트도 본문과 함께 옮겨짐
      (.hwp는 DEC-032, .hwpx는 DEC-052부터 — 예전엔 이 부분이 통째로
      빠졌던 항목이라 특히 꼼꼼히 확인)

### 2-4. DOCX → PDF / PPTX → PDF (`01_한글테스트.docx`, `02_한글테스트.pptx`)

- [ ] 뷁·밟·닳 등 드문 글자, 大韓民國 등 한자가 빈 네모(□) 없이 정상 표시
- [ ] 표·서식이 원본과 시각적으로 일치

### 2-5. PDF → DOCX (`03_한글테스트_PDF에서시작.pdf`)

- [ ] 각 줄이 원본과 같은 위치에 배치됨(절대 위치 레이아웃, DEC-037)
- [ ] 글자가 위·아래로 잘리지 않고 온전히 보임(디센더(g/p/q/y 등)까지
      포함 — 텍스트 프레임 클리핑 결함 수정, DEC-057)
- [ ] 이어서 타이핑했을 때 줄이 자연스럽게 안 이어질 수 있다는 트레이드
      오프를 실제로 체감해보고, 변환 전 고지 문구가 이를 정확히
      설명하는지 확인
- [ ] 표 테두리(품목 표의 가로·세로 선)가 원래 위치에 그려짐(이미지·표
      테두리 반영, DEC-054) — 번들 샘플엔 이미지·밑줄이 없어 아래 두
      항목은 이미지·밑줄이 있는 본인 PDF로 확인:
- [ ] (본인 PDF, 이미지 포함) 이미지가 원래 위치·크기로 삽입됨
- [ ] (본인 PDF, 밑줄 있는 텍스트 포함) 밑줄이 있는 부분만 정확히
      밑줄로 반영되고 나머지는 안 그럼(밑줄 감지, DEC-055)

### 2-6. PDF → PPTX

- [ ] 텍스트가 원본과 같은 위치·크기로 편집 가능한 텍스트 상자로 나옴
- [ ] 이미지·표 테두리(사각형/직선)가 재구성됨(복잡한 곡선은 다각형
      근사라 완전히 매끄럽지 않을 수 있음 — 정상)

### 2-7. PDF → PNG / JPG

- [ ] 원본 파일명 폴더가 생성되고 페이지별 이미지가 순서대로 저장됨
- [ ] 텍스트·표가 페이지 그대로 선명하게 보임

## 3. 데이터·영상·이미지 변환

### 3-1. XLSX → CSV (`05_한글테스트_엑셀시트.xlsx`)

- [ ] 시트가 여러 개면 "첫 시트만 변환" 고지가 뜸
- [ ] 날짜가 `2026-07-31`처럼(시간 안 붙고) 나옴
- [ ] 정수가 `3.0`이 아니라 `3`으로 나옴

### 3-2. CSV ↔ XLSX, CSV ↔ JSON

- [ ] 왕복 변환 후 데이터 손실·인코딩 깨짐 없음(한글 포함)

### 3-3. 영상 → MP4

- [ ] H.264/HEVC 소스는 정상 변환되고(무손실 스트림 카피, 사실상 즉시
      완료) 결과 파일이 재생됨
- [ ] 그 외 코덱(Xvid·MPEG-2 등) 파일은 h264_mf로 재인코딩돼 변환되고
      결과 파일이 정상 재생됨(DEC-060 — 예전엔 거부했던 경로). 화질이
      원본과 비교해 눈에 띄게 나쁘지 않은지도 확인(libx264만큼은 아닐
      수 있음이 알려진 한계)
- [ ] (재인코딩이 정말 실패하는 극히 드문 경우가 있다면) 명확한 오류
      메시지로 거부됨(조용히 실패하지 않음)

### 3-4. 이미지 상호 변환(JPG/PNG/BMP/GIF/WEBP/TIFF)

- [ ] EXIF 회전이 반영된 방향으로 저장됨
- [ ] 투명 배경 있는 이미지 → 투명 미지원 포맷 변환 시 흰 배경으로 합성됨
- [ ] 애니메이션 GIF/WEBP → 다른 포맷 변환 시 첫 프레임만 남는다는 고지가
      뜨고 실제로 그렇게 됨

### 3-5. TXT/MD/HTML 상호 변환(DEC-061)

자동 테스트는 HTML 문자열 구조만 확인하고 실제 브라우저 렌더링은 검증하지
못한다 — 결과 HTML 파일을 실제 브라우저(더블클릭)로 열어 확인할 것.

- [ ] MD → HTML: 표·굵게/기울임·코드블록이 브라우저에서 실제로 표·굵게
      등으로 렌더링됨(원문 기호가 그대로 텍스트로 보이지 않음)
- [ ] HTML → MD: 제목 태그(`<title>`) 내용이 결과 MD 본문에 섞여
      들어가지 않음
- [ ] TXT → MD/HTML: `#`·`*`·`1.`·`[각주]`처럼 마크업 기호로 시작하는
      줄이 실제 제목·목록·링크로 오인되지 않고 원본 그대로 보임
- [ ] MD → TXT: 표가 포함된 문서를 변환하면 열 정렬은 사라지지만 셀
      내용 자체는 유실 없이 남음(알려진 한계)

## 4. 일반 UI·플랫폼 동작

- [ ] 여러 파일(혼합 포맷)을 한 번에 넣고 일괄 변환 — 일부 실패해도
      나머지는 계속 진행되고 성공/실패 요약이 보임
- [ ] 지원하지 않는 파일(예: 실행 파일)을 넣으면 명확한 안내가 뜸
- [ ] 최근 변환 기록 패널에서 파일 위치를 열 수 있고, 기록 삭제가 됨
- [ ] 우측 상단 설정에서 한국어/영어 전환이 즉시 반영됨
- [ ] 설정의 "새 버전 알림"을 켜면(옵트인) 버전 확인이 되고, 껐을 땐
      네트워크 요청이 전혀 없음(REQ-NF-002 — 필요시 프록시/방화벽 로그로
      확인)
- [ ] 결과 오버레이가 저해상도(640×480 근처)에서도 "확인"/"폴더 열기"
      버튼이 항상 보임(스크롤로 접근 가능, DEC-045)
- [ ] 기록 패널을 열어도 파일 목록 항목(콤보박스·제거 버튼)이 잘리지
      않음(DEC-047)

```

    화면 캡처면 더 좋음, 단축키 Win+Shift+S)
  - 사용한 파일 (샘플 파일 / 본인 파일 — 본인 파일이면 문서 종류)
  - Windows 버전, 한글/Word 버전(문서 변환 항목의 경우)
```
