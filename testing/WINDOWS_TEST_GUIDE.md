# 파일 변환기 — Windows 테스트 가이드 (v0.3.3)

테스트해 주셔서 감사합니다! 지난번 발견해 주신 두 가지 문제(PDF→DOCX 글자 깨짐,
DOCX→PDF 일부 글자 삭제)를 원인을 찾아 고쳤고, PPTX(파워포인트) 변환도 새로 추가했습니다.
이번엔 그 부분이 실제로 고쳐졌는지 확인 부탁드립니다.

## 0. 준비물

- `testing/samples/` 폴더의 샘플 파일 3개(아래 표) — 이번에 고친 문제를 정확히 겨냥해 만든
  테스트용 파일입니다. 본인이 가진 실제 문서로도 자유롭게 테스트해 주시면 더 좋습니다.
- 설치 파일 바로 다운로드: **[v0.3.3 설치 파일](https://github.com/jh3779/file-converter/releases/download/v0.3.3/FileConverter-Setup-latest.exe)**
  (저장소가 공개 전환되어 로그인 없이 바로 받으실 수 있습니다)

| 파일 | 용도 |
|---|---|
| `01_한글테스트.docx` | DOCX→PDF 테스트용 — 드문 한글 자모·한자·표 포함 |
| `02_한글테스트.pptx` | PPTX→PDF 테스트용(신규 기능) |
| `03_한글테스트_PDF에서시작.pdf` | PDF→DOCX 테스트용 — 지난번 "글자가 깨진다"고 하셨던 방향 |

## 1. 설치 확인

1. 다운로드한 `FileConverter-Setup-*.exe` 실행
2. **관리자 권한 요청(UAC 창)이 뜨지 않는지** 확인 — 뜨면 알려주세요(원래는 안 뜨는 게 맞습니다)
3. 설치 마법사 언어가 한국어로 나오는지 확인
4. 설치 완료 후 바탕화면/시작 메뉴에 "File Converter" 바로가기가 생겼는지 확인
5. 바로가기로 앱이 정상적으로 열리는지 확인

## 2. 핵심 재현 테스트 — 이번에 고친 부분

### 2-1. DOCX → PDF (`01_한글테스트.docx`)
1. 앱에 파일을 끌어다 놓고 PDF로 변환
2. 결과 PDF를 열어서 **다음 문장이 전부 온전하게 보이는지** 확인해 주세요:
   - `뷁 밟 닳 넋 앎 옳 훑 흙 삵 값 넓 얹 앉 닭 없` (드문 한글 자모 조합)
   - `大韓民國 韓國語 漢字 契約書 委任狀` (한자)
   - 표 안의 "함초롬바탕 서식" 등 텍스트
3. **지난번처럼 특정 글자가 사라지거나 빈 네모(□)로 보이는 부분이 있는지** 확인

### 2-2. PDF → DOCX (`03_한글테스트_PDF에서시작.pdf`)
1. 이 PDF를 앱에 넣고 DOCX로 변환
2. 결과 DOCX를 **한글(HWP) 또는 MS Word로 열어서** 글자 모양이 정상인지 확인
   - 지난번 "글자의 형태가 다 깨지는" 문제가 재현되는지가 핵심입니다
   - 뷁·밟·닳 같은 드문 글자, 표 안의 내용까지 확인 부탁드립니다

### 2-3. PPTX → PDF (`02_한글테스트.pptx`, 신규 기능)
1. 이 파일을 앱에 넣으면 PDF 옵션이 뜨는지 확인(새로 추가된 기능)
2. PDF로 변환 후 슬라이드 2장의 한글·한자가 정상적으로 보이는지 확인

## 3. 그 외 일반 확인 (시간 되실 때)

- [ ] 본인이 실제 갖고 계신 DOCX/HWP/PDF 파일로도 변환 — 특히 업무에서 쓰시는
      실제 문서(계약서, 공문 등)가 있다면 더 좋습니다
- [ ] 여러 파일을 한 번에 넣고 일괄 변환이 잘 되는지
- [ ] CSV ↔ XLSX, CSV ↔ JSON 변환
- [ ] 지원하지 않는 파일(예: 이미지 파일)을 넣었을 때 안내 문구가 뜨는지
- [ ] 우측 상단 ⚙ 메뉴에서 한국어/영어 전환이 되는지
- [ ] 프로그램 제거(제어판 → 프로그램 제거) 시 깨끗하게 지워지는지

## 4. 결과 보내주실 때

아래 형식으로 알려주시면 빠르게 확인하겠습니다.

```
[테스트한 항목]  예: 2-1 DOCX→PDF
[결과]  정상 / 문제 있음
[문제가 있다면]
  - 어떤 글자·부분이 어떻게 보였는지 (스크린샷 첨부해 주시면 가장 정확합니다)
  - 사용하신 파일 (샘플 파일 / 본인 파일 — 본인 파일이면 어떤 종류의 문서였는지)
  - Windows 버전 (예: Windows 11)
```

스크린샷은 문제가 된 화면을 그대로 캡처해 주시면 됩니다(단축키: `Win + Shift + S`).

감사합니다!
