# 파일 변환기 — Windows 테스트 가이드 (v0.3.8)

테스트해 주셔서 감사합니다! 이번 버전의 핵심은 **DOCX의 표를 HWP로 변환할 때
텍스트로 뭉개지 않고 실제 표(칸 구분이 있는 진짜 표)로 만드는 신규 기능**입니다.
지금까지는 표가 "이름 | 부서"처럼 한 줄 텍스트로 단순화됐는데, 이제는 실제 한글
표로 생성됩니다. 이 기능은 저희 개발 환경(Mac)에는 실제 한글 프로그램이 없어서
자체적으로 최종 확인을 못 했습니다 — **한글(HWP) 프로그램에서 직접 열어 표가
진짜 표 모양(칸·테두리)으로 보이는지 확인해 주시는 게 이번 테스트에서 가장
중요합니다.**

## 0. 준비물

- `testing/samples/` 폴더의 샘플 파일 5개(아래 표) — 이번에 추가·수정한 기능을 정확히
  겨냥해 만든 테스트용 파일입니다. 본인이 가진 실제 문서로도 자유롭게 테스트해 주시면
  더 좋습니다(특히 표·번호 목록이 많은 실제 업무 문서라면 더 좋습니다).
- 설치 파일 바로 다운로드: **[v0.3.8 설치 파일](https://github.com/jh3779/file-converter/releases/download/v0.3.8/FileConverter-Setup-latest.exe)**
  (저장소가 공개 전환되어 로그인 없이 바로 받으실 수 있습니다)
- 한글(HWP) 프로그램 — 이번 테스트 2-1에서 꼭 필요합니다

| 파일 | 용도 |
|---|---|
| `04_한글테스트_DOCX에서HWP로.docx` | **DOCX→HWP 테스트용(신규 기능, 최우선)** — 긴 문단·번호 목록·불릿·표·한자 포함 |
| `05_한글테스트_엑셀시트.xlsx` | XLSX→CSV 테스트용(신규) — 날짜·소수 표시 형식, 시트 2개 |
| `01_한글테스트.docx` | DOCX→PDF 테스트용 — 드문 한글 자모·한자·표 포함 |
| `02_한글테스트.pptx` | PPTX→PDF 테스트용 |
| `03_한글테스트_PDF에서시작.pdf` | PDF→DOCX 테스트용 |

## 1. 설치 확인

1. 다운로드한 `FileConverter-Setup-*.exe` 실행
   - 이때 Windows SmartScreen이 "인식할 수 없는 앱" 파란 경고창을 띄울 수 있습니다 —
     코드 서명 인증서가 없는 사이드 프로젝트라 정상적으로 뜨는 것입니다(바이러스 경고
     아님). **"추가 정보" → "실행"**을 누르면 계속 진행됩니다.
2. **관리자 권한 요청(UAC 창)이 뜨지 않는지** 확인 — 뜨면 알려주세요(원래는 안 뜨는 게 맞습니다)
3. 설치 마법사 언어가 한국어로 나오는지 확인
4. 설치 완료 후 바탕화면/시작 메뉴에 "File Converter" 바로가기가 생겼는지 확인
5. 바로가기로 앱이 정상적으로 열리는지 확인

## 2. 핵심 테스트 — 이번 버전에서 새로 생기거나 고친 부분

### 2-1. DOCX → HWP (`04_한글테스트_DOCX에서HWP로.docx`, 신규 기능·최우선) ⭐

1. 앱에 파일을 끌어다 놓고 **HWP**로 변환
2. 변환 전 화면에 "레이아웃이 단순화될 수 있어요 — 텍스트·표 내용은 유지됩니다"
   안내 문구가 보이는지 확인
3. **결과 HWP 파일을 한글(HWP) 프로그램으로 직접 열어서** 다음을 확인해 주세요:
   - [ ] **(가장 중요, 신규) 표가 "이름 | 부서"처럼 한 줄 텍스트가 아니라 실제 칸·테두리가
         있는 진짜 표로 보이는지** — 이번에 새로 생긴 기능이라 가장 정확히 봐주셔야
         하는 항목입니다. 표 모양이 이상하게 깨져 보이거나(칸이 겹침, 위치가 이상함 등)
         아예 표가 안 보이면 꼭 알려주세요
   - [ ] 표 안 내용("이름/부서/비고", "김철수/영업1팀/정상" 등)이 각 칸에 맞게
         빠짐없이 들어가 있는지
   - [ ] 두 번째 문단(일부러 길게 쓴 문단)이 **여러 줄로 자연스럽게 줄바꿈**되어 보이는지,
         혹은 **문단끼리 겹치거나 형태가 깨져 보이는지**
   - [ ] 번호 목록("1. 첫 번째 할 일" 등)과 불릿("• 참고 사항")이 그대로 보이는지
   - [ ] 뷁·밟·닳 같은 드문 글자, 大韓民國 같은 한자가 정상적으로 보이는지(표 안 내용
         포함)

### 2-2. XLSX → CSV (`05_한글테스트_엑셀시트.xlsx`, 표시 형식 개선)

1. 앱에 파일을 끌어다 놓고 CSV로 변환
2. 변환 전 화면에 "시트가 여러 개예요 — 첫 번째 시트만 변환돼요" 안내 문구가 보이는지 확인
   (이 파일은 일부러 시트를 2개로 만들었습니다 — "메모" 시트는 변환 안 되는 게 정상입니다)
3. 결과 CSV를 엑셀로 열어서 확인:
   - [ ] 날짜가 `2026-07-31`처럼 보이는지 (`2026-07-31 00:00:00`처럼 시간이 붙어 있으면 문제)
   - [ ] 수량 `3`이 `3.0`이 아니라 `3`으로 보이는지
   - [ ] "매출현황" 시트 내용만 있고 "메모" 시트 내용은 없는지

### 2-3. DOCX → PDF (`01_한글테스트.docx`)
1. 앱에 파일을 끌어다 놓고 PDF로 변환
2. 결과 PDF에서 `뷁 밟 닳 넋 앎 옳 훑 흙 삵 값 넓 얹 앉 닭 없`, `大韓民國 韓國語 漢字 契約書 委任狀`,
   표 안의 "함초롬바탕 서식" 등 텍스트가 온전히 보이는지, 빈 네모(□)로 보이는 부분이 없는지 확인

### 2-4. PDF → DOCX (`03_한글테스트_PDF에서시작.pdf`)
1. 이 PDF를 앱에 넣고 DOCX로 변환
2. 결과 DOCX를 한글(HWP) 또는 MS Word로 열어서 글자 모양이 정상인지 확인

### 2-5. PPTX → PDF (`02_한글테스트.pptx`)
1. 이 파일을 앱에 넣으면 PDF 옵션이 뜨는지 확인
2. PDF로 변환 후 슬라이드 2장의 한글·한자가 정상적으로 보이는지 확인

## 3. 그 외 일반 확인 (시간 되실 때)

- [ ] 본인이 실제 갖고 계신 DOCX 파일로 HWP 변환 — 특히 번호 목록·표가 있는 실제 업무
      문서(계약서, 공문 등)가 있다면 더 좋습니다
- [ ] 여러 파일을 한 번에 넣고 일괄 변환이 잘 되는지
- [ ] CSV ↔ XLSX, CSV ↔ JSON 변환
- [ ] 지원하지 않는 파일(예: 이미지 파일)을 넣었을 때 안내 문구가 뜨는지
- [ ] 우측 상단 ⚙ 메뉴에서 한국어/영어 전환이 되는지
- [ ] 프로그램 제거(제어판 → 프로그램 제거) 시 깨끗하게 지워지는지

## 4. 결과 보내주실 때

아래 형식으로 알려주시면 빠르게 확인하겠습니다.

```
[테스트한 항목]  예: 2-1 DOCX→HWP
[결과]  정상 / 문제 있음
[문제가 있다면]
  - 어떤 글자·부분이 어떻게 보였는지 (스크린샷 첨부해 주시면 가장 정확합니다.
    2-1은 한글 프로그램 화면 스크린샷이면 더 좋습니다)
  - 사용하신 파일 (샘플 파일 / 본인 파일 — 본인 파일이면 어떤 종류의 문서였는지)
  - Windows 버전 (예: Windows 11), 한글 프로그램 버전(2-1의 경우)
```

스크린샷은 문제가 된 화면을 그대로 캡처해 주시면 됩니다(단축키: `Win + Shift + S`).
