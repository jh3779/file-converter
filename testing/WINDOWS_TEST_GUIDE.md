# 파일 변환기 — Windows 테스트 가이드 (v0.3.16)

테스트해 주셔서 감사합니다! 이번 v0.3.16은 새 기능보다 **안정성 버그
수정 위주**입니다. 아래는 이번 버전에서 새로 고친 부분만 골라 안내합니다
— 전체 변환 경로를 훑어보는 상시 회귀 테스트는 `MANUAL_TEST_CHECKLIST.md`
를 참고해 주세요.

## 0. 준비물

- 설치 파일 바로 다운로드: **[v0.3.16 다운로드](https://github.com/jh3779/file-converter/releases/download/v0.3.16/FileConverter-Setup-latest.exe)**
- 아래 2-1은 메모장으로 직접 짧은 CSV를 하나 만들어야 합니다(별도 샘플
  파일 불필요)
- 2-2는 H.264/HEVC가 아닌 코덱으로 인코딩된 영상 파일이 있으면 좋습니다
  (없으면 건너뛰어도 무방)

## 1. 설치 확인

1. 다운로드한 `FileConverter-Setup-*.exe` 실행
   - 이때 Windows SmartScreen이 **빨간 "Windows의 PC 보호" 화면으로 실행을 막습니다**
     (경고가 아니라 차단 — 코드 서명 인증서가 없는 사이드 프로젝트라 정상적으로 뜨는
     것입니다, 바이러스 경고 아님). 이 첫 화면엔 "실행" 버튼이 없습니다 — 화면 안의
     (버튼이 아닌) **"추가 정보"** 텍스트를 누르면 "실행" 버튼이 나타납니다, 그걸 누르면
     계속 진행됩니다.
2. **"설치 모드 선택" 화면이 뜹니다** — "나만 사용하도록 설치"(권장, 기본값)를 그대로
   두고 진행해 주세요. 이 기본값을 선택하면 **관리자 권한(UAC)이 필요 없습니다** — 만약
   UAC 창이 떴다면 "모든 사용자용으로 설치"를 실수로 골랐을 가능성이 높으니 알려주세요
   (기본값 그대로면 UAC가 뜨는 게 비정상입니다)
3. 설치 마법사 언어가 한국어로 나오는지 확인
4. 설치 완료 후 바탕화면/시작 메뉴에 "File Converter" 바로가기가 생겼는지 확인
5. 바로가기로 앱이 정상적으로 열리는지 확인

## 2. 이번 버전(v0.3.16)에서 새로 고친 부분

### 2-1. CSV → JSON, 행마다 컬럼 개수가 다를 때 데이터가 안 사라지는지 ⭐

메모장 등으로 아래처럼 **헤더보다 데이터 값이 더 많은 CSV**를 하나 만들어
주세요(예: `test.csv`):

```
이름,부서
김철수,영업1팀,정상,추가메모
이영희,개발팀
```

1. 이 CSV를 앱에 넣고 **JSON**으로 변환
2. 결과 JSON 파일을 열어서, 첫 번째 행의 초과된 값("정상", "추가메모")이
   `_extra`류의 키에 그대로 들어있는지 확인해 주세요 — **예전 버전은 이
   초과 값들을 조용히 버렸습니다(데이터 손실 버그)**, 이번에 고친 부분이라
   빠짐없이 보존되는 게 정상입니다

### 2-2. 지원하지 않는 코덱 영상의 오류 문구

H.264/HEVC가 아닌 코덱(Xvid·MPEG-2 등)으로 인코딩된 영상 파일이 있다면:

1. 이 영상 파일을 앱에 넣고 **MP4**로 변환 시도
2. Windows에서는 재인코딩(h264_mf)을 거쳐 **성공하는 것이 정상**입니다
   (예전 버전은 이런 코덱을 무조건 거부했습니다) — 화면 문구가 "지원하지
   않는 코덱"이 아니라 실제 동작(재인코딩 처리)에 맞게 보이는지 확인해
   주세요
3. (극히 드물게 재인코딩 자체가 실패하는 경우) 오류 문구가 무엇이 문제인지
   명확히 안내하는지 확인

### 2-3. 변환 중 앱을 바로 닫아도 안전한지

1. 여러 파일을 넣고 변환이 진행 중인 상태에서 곧바로 앱을 닫아 주세요
   (X 버튼)
2. 다시 앱을 열어 우측 상단 기록(🕐) 패널을 확인 — 앱이 오류 없이
   정상적으로 열리고, 그전에 완료됐던 변환 기록이 그대로 남아있는지
   확인해 주세요(예전 버전은 변환 중 종료 시 기록 저장소 연결이 제대로
   안 닫히는 리소스 누수가 있었습니다)

## 3. 그 외 일반 확인 (시간 되실 때)

- [ ] 여러 파일을 한 번에 넣고 일괄 변환이 잘 되는지
- [ ] CSV ↔ XLSX 변환
- [ ] 지원하지 않는 파일(예: 실행 파일)을 넣었을 때 안내 문구가 뜨는지
- [ ] 우측 상단 ⚙ 메뉴에서 한국어/영어 전환이 되는지
- [ ] 프로그램 제거(제어판 → 프로그램 제거) 시 깨끗하게 지워지는지

새 기능(HWPX·3D 모델·TXT/MD/HTML·영상 스트림 카피 등)까지 폭넓게
확인하고 싶으시면 `MANUAL_TEST_CHECKLIST.md`의 해당 절을 참고해 주세요.

## 4. 결과 보내주실 때

아래 형식으로 알려주시면 빠르게 확인하겠습니다.

```
[테스트한 항목]  예: 2-1 CSV→JSON 초과 컬럼
[결과]  정상 / 문제 있음
[문제가 있다면]
  - 어떤 부분이 어떻게 보였는지 (스크린샷 첨부해 주시면 가장 정확합니다)
  - 사용하신 파일 (직접 만든 샘플 / 본인 파일 — 본인 파일이면 어떤 종류의 문서였는지)
  - Windows 버전 (예: Windows 11)
```

스크린샷은 문제가 된 화면을 그대로 캡처해 주시면 됩니다(단축키: `Win + Shift + S`).
