4. LibreOffice (headless 변환 엔진 — DOCX→PDF, HWP→PDF)
   - 경로: engine/libreoffice/
   - 저작권: The Document Foundation — https://www.libreoffice.org
   - 라이선스: Mozilla Public License 2.0 (일부 구성요소 LGPLv3) —
     전문은 engine/licenses/libreoffice/ 디렉터리 참조
   - 번들 버전: 26.2.5 (Windows x86_64, 공식 배포 서버 SHA256 검증 — DEC-012)
   - 배포 방식: 공식 설치파일(MSI)의 "관리자 설치(administrative install,
     msiexec /a)"로 파일만 추출 — 시스템에 실제 설치·레지스트리 등록 없이
     프로그램 파일만 앱에 동봉. MPL 2.0은 이러한 바이너리 재배포를 허용한다.
   - 알려진 제약: Microsoft Visual C++ 런타임이 전혀 없는 완전히 새 Windows
     환경에서는 soffice.exe 실행이 실패할 수 있다(별도 검증 필요 — DEC-012).

5. Noto Sans KR (한글 글꼴 — DOCX/HWP→DOCX 생성 문서 및 LibreOffice 렌더링용)
   - 경로: engine/libreoffice/share/fonts/truetype/NotoSansKR-{Regular,Bold}.otf
   - 저작권: Google — https://github.com/notofonts/noto-cjk
   - 라이선스: SIL Open Font License 1.1 — 전문은
     engine/licenses/notosanskr/LICENSE.txt 참조
   - 번들 릴리스: Sans2.004 (17_NotoSansKR.zip, SHA256 검증)
   - 포함 이유(DEC-015): 번들 LibreOffice 자체에는 한글 글꼴이 전혀 없어
     호스트 Windows에 설치된 글꼴에만 의존하면 일부 문자가 누락될 수 있음이
     실사용 중 확인됨. hwplib/PDF에서 생성하는 DOCX는 이 글꼴을 모든 run에
     명시적으로 지정한다. 사용자가 직접 제공한 DOCX/PPTX(글꼴 미지정)의
     DOCX→PDF 렌더링은 호스트 글꼴 가용성에 여전히 일부 의존한다(잔여 리스크).

7. FFmpeg (영상→MP4 변환 엔진)
   - 경로: engine/ffmpeg/
   - 저작권: FFmpeg 프로젝트 — https://ffmpeg.org
   - 라이선스: GNU Lesser General Public License v2.1+ — 전문은
     engine/licenses/ffmpeg/LICENSE.txt 참조. GPL 전용 구성요소(libx264 등)는
     포함하지 않은 빌드(BtbN/FFmpeg-Builds, win64-lgpl-shared)를 사용한다.
   - 번들 빌드: FFmpeg n7.1 (Windows x86_64, 다운로드 서버 SHA256 검증)
   - 범위(DEC-024): 영상 스트림은 H.264/HEVC일 때만 재인코딩 없이 그대로
     복사한다(무손실). 그 외 코덱은 v1에서 지원하지 않는다 — 영상
     인코더(libx264 등)를 아예 번들하지 않으므로 재인코딩 자체가 불가능하고,
     이 선택이 라이선스·화질 트레이드오프를 모두 피하게 해준다. 오디오는
     AAC가 아니면 FFmpeg 내장 AAC 인코더(외부 라이브러리 불필요, LGPL 코어
     포함)로만 재인코딩한다.
