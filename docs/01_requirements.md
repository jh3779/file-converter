# 01. 요구사항 (Requirements)

> 인터뷰 영역 4·7 (범위·MVP / 제약·비기능) 정리 · 상태: draft

## 범위 — MoSCoW
| 구분 | 항목 | 근거 |
|------|------|------|
| **Must** | DOCX→PDF, PPTX→PDF, PDF→TXT/DOCX, HWP→PDF/TXT/DOCX(읽기 전용), CSV↔XLSX, CSV↔JSON, 일괄 변환, 드래그앤드롭, 원본 보호 | REQ-F-001~008·012 |
| Should | 인코딩 자동 감지(EUC-KR/UTF-8, 한글 깨짐 방지), 최근 변환 기록, 업데이트 확인(옵트인), 영상→MP4(H.264/HEVC만), 이미지 포맷 상호 변환(JPG/PNG/BMP/GIF/WEBP/TIFF), PDF→이미지(페이지별 폴더) | REQ-F-009~010·013~016 |
| Could | 영상 코덱 재인코딩 확장(Xvid 등, DEC-024 잔여 리스크), TXT/MD/HTML 상호 변환, DOCX→HWP 표 셀 병합 지원, DOCX→HWP·PDF→HWP 쓰기 방향 문자 서식(굵게 등, DEC-027은 읽기 방향만 완료) | — |
| **Won't (MVP 제외)** | OCR(스캔 PDF 문자 인식), 파일 미리보기/편집, 클라우드·계정 기능 | 범위 통제 |

## 기능 요구사항 (REQ-F-*)
| ID | 요구사항 | 우선순위 | 관련 SCR/FLOW |
|----|----------|:--------:|---------------|
| REQ-F-001 | 사용자는 파일을 드래그앤드롭(또는 클릭 선택)으로 앱에 추가할 수 있다 | Must | FLOW-001 · SCR-001 |
| REQ-F-002 | 사용자는 파일별로 변환 대상 포맷을 선택할 수 있다 (확장자에 따라 가능한 포맷만 노출) | Must | FLOW-001 · SCR-001 |
| REQ-F-003 | 사용자는 DOCX를 PDF로 변환할 수 있다 | Must | FLOW-001 |
| REQ-F-004 | 사용자는 PDF에서 TXT/DOCX를 추출·변환할 수 있다. DOCX 결과에는 굵게/기울임/글자크기가 반영된다(폰트 리소스 이름 기반 휴리스틱 — 100% 정확 보장 안 함, DEC-027). 밑줄은 반영하지 않는다(PDF는 밑줄을 폰트 속성이 아닌 별도 벡터 선으로 그리는 경우가 많아 이 휴리스틱으로 판별 불가) | Must | FLOW-001 |
| REQ-F-005 | 사용자는 HWP를 PDF/TXT/DOCX로 변환할 수 있고, DOCX·PDF를 HWP로 변환할 수 있다. DOCX→HWP는 표를 실제 HWP 표로 새로 생성한다(셀 병합 미지원, PDF는 애초에 표 구조가 없어 해당 없음 — DEC-028). HWP→DOCX 결과에는 굵게/기울임/밑줄/글자크기/색상이 반영된다(DEC-027) | Must | FLOW-001 · OQ-001 · DEC-017 · DEC-023 · DEC-027 · DEC-028 |
| REQ-F-006 | 사용자는 CSV↔XLSX, CSV↔JSON을 상호 변환할 수 있다 | Must | FLOW-001 |
| REQ-F-007 | 사용자는 여러 파일을 한 번에 넣어 일괄 변환할 수 있다 (혼합 포맷 허용) | Must | FLOW-001 |
| REQ-F-008 | 변환 결과는 원본 폴더에 저장되고, 이름 충돌 시 자동으로 `(1)` 등을 붙인다. 원본은 절대 수정되지 않는다 | Must | FLOW-001 · INV-01 |
| REQ-F-009 | 일괄 변환 중 일부 실패 시 나머지는 계속 진행하고, 완료 후 성공/실패 요약과 실패 사유를 보여준다 | Must | FLOW-001 · SCR-002 |
| REQ-F-010 | 사용자는 최근 변환 기록(N건)을 보고 결과 파일 위치를 열 수 있으며, 기록을 삭제할 수 있다 | Should | SCR-003 |
| REQ-F-011 | 사용자는 UI 언어를 한국어/영어 중 선택할 수 있다 (기본: 시스템 언어 감지, 그 외 언어는 영어) | Must | SCR-001 · DEC-009 |
| REQ-F-012 | 사용자는 PPTX를 PDF로 변환할 수 있다 | Must | FLOW-001 · DEC-016 |
| REQ-F-013 | 사용자는 설정에서 업데이트 확인을 켤 수 있다(기본 꺼짐, 옵트인). 켜져 있으면 버전 번호만 조회해 새 버전이 있을 때 조용히 안내한다 — 자동 다운로드·설치는 하지 않는다 | Should | SCR-001 · DEC-022 |
| REQ-F-014 | 사용자는 영상 파일(AVI/MOV/MKV/WMV/FLV/M4V)을 MP4로 변환할 수 있다 (영상 스트림이 H.264/HEVC일 때만 지원 — 그 외 코덱은 명확한 오류로 거부. WEBM은 표준상 VP8/VP9/AV1만 담아 이 범위와 사실상 항상 불일치해 제외) | Should | FLOW-001 · DEC-024 |
| REQ-F-015 | 사용자는 이미지 파일(JPG/JPEG/PNG/BMP/GIF/WEBP/TIFF)을 서로 다른 이미지 포맷으로 변환할 수 있다. EXIF 회전 정보가 반영되고, 투명 배경은 대상 포맷이 투명을 지원하지 않으면 흰 배경으로 합성된다. 애니메이션 이미지는 항상 첫 프레임만 변환된다(고지 표시) | Should | FLOW-001 · DEC-025 |
| REQ-F-016 | 사용자는 PDF를 이미지로 변환할 수 있다 — 원본 파일명 폴더가 생성되고 그 안에 페이지별 PNG가 저장된다 | Should | FLOW-001 · DEC-026 |

## 비기능 요구사항 (REQ-NF-*)
| ID | 항목 | 기준 |
|----|------|------|
| REQ-NF-001 | 플랫폼 | Windows·macOS(Apple Silicon 전용, 미서명) 배포. macOS는 영상→MP4 미지원(DEC-029). 크로스 플랫폼 설계 필수 |
| REQ-NF-002 | 오프라인 | **모든 변환이 로컬에서 처리, 파일 내용은 절대 네트워크로 전송되지 않음.** 기본 상태에서 네트워크 요청 0건. 유일한 예외: 사용자가 설정에서 직접 켜야 하는(옵트인, 기본 꺼짐) 업데이트 확인 — 버전 번호만 조회, 파일·경로·식별 정보 미전송 (DEC-022, OQ-002 해결) |
| REQ-NF-003 | 프라이버시 | 파일 내용을 외부 전송·수집하지 않음. 변환 기록은 로컬에만 저장 |
| REQ-NF-004 | 정확도 | 문서 레이아웃·글꼴·표 보존(엔진 번들 기준), 데이터 변환 시 한글 인코딩 깨짐 없음 |
| REQ-NF-005 | 단독 동작 | MS 오피스·한글(HWP) 등 외부 프로그램 설치 불요. 변환 엔진(LibreOffice 계열) 앱에 번들 |
| REQ-NF-006 | 사용성 | 설명서 없이 3클릭(파일 넣기→포맷 선택→변환)으로 완결 |
| REQ-NF-007 | 원본 보호 | 원본 파일은 읽기 전용으로만 접근. 덮어쓰기 경로 자체가 존재하지 않음 |

## 제약
- **기술 스택:** [06_open_questions.md](06_open_questions.md) DEC-001 참조 — Python + PySide6(Qt) + 번들 LibreOffice 엔진 (추천안 확정).
- **일정/투입:** 사이드 프로젝트. 기한 없이 품질 우선, 범위는 MoSCoW로 통제.
- **되돌릴 수 없는 동작:** 없음(원본 비수정 원칙). 유일한 삭제는 "최근 기록 삭제"이며 기록 메타데이터만 지우고 파일은 건드리지 않는다.
