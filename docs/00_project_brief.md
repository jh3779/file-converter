# 00. 프로젝트 브리프

> 인터뷰 영역 1~3 (문제·목표 / 사용자·맥락 / 가치·성공 지표) 정리
> 작성일: 2026-07-29 · 상태: draft

## 한 문장 정의
이 제품은 **비개발자 일반인**이 **문서·데이터 파일의 포맷 변환**을 **인터넷 연결 없이, 하나의 데스크톱 앱에서 드래그앤드롭으로** 끝내도록 돕는다.

## 문제 · 목표 (왜)
- **푸는 문제:** 파일 포맷마다 다른 도구가 필요하다. 문서는 오피스/한글, 데이터는 엑셀이나 온라인 변환 사이트… 포맷별로 도구를 찾아다녀야 하고, 온라인 변환 사이트는 파일 업로드에 대한 보안 불안이 있다.
- **현행 대안:** 포맷별 개별 프로그램 실행, 또는 온라인 변환 사이트에 파일 업로드.
- **성공 시 변화:** 어떤 문서/데이터 파일이든 이 앱 하나에 끌어다 놓으면 변환이 끝난다. 파일이 PC 밖으로 나가지 않는다.

## 대상 사용자 · 맥락
| 항목 | 내용 |
|------|------|
| 1차 사용자 | 비개발자 일반인 (기술에 익숙하지 않은 사용자) |
| 2차 사용자/수신자 | — (개인 로컬 도구, 공유 기능 없음) |
| 사용 맥락 | 데스크톱 PC(Windows 우선), 필요할 때 수시 사용, **오프라인 환경 포함** |

## 핵심 가치 · 성공 지표
- **핵심 가치:** 완전 오프라인 — 파일이 절대 PC 밖으로 나가지 않는 변환기.
- **성공 지표(제안):** 첫 실행에서 설명 없이 변환 성공(3클릭 이내 완결률), 변환 성공률, 재사용 빈도.
- **반드시 지킬 품질:**
  1. **변환 결과 정확도** — 문서 레이아웃·글꼴·표, 데이터 인코딩(한글 깨짐 없음) 보존
  2. **원본 파일 보호** — 어떤 경우에도 원본을 덮어쓰거나 손상시키지 않음
  3. **설치 간편함** — 오피스·한글 등 별도 프로그램 없이 단독 동작

## 비전 대비 MVP 경계 (요약)
MVP는 **문서(DOCX→PDF, PPTX→PDF, PDF→TXT/DOCX, HWP 읽기) + 데이터(CSV↔XLSX, CSV↔JSON) + 일괄 변환**까지. OCR, 미리보기/편집, 이미지·미디어 확장은 [01_requirements.md](01_requirements.md) Could/Won't 참조.
