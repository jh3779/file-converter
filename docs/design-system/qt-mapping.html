M-03상태 머신 → 스레딩 모델STATE-001·002 · INV-01~05
· UI 스레드는 변환하지 않는다. ConversionJob = QThreadPool, FileItem 1개 = QRunnable 1개(동시 실행 수 = min(CPU-1, 4)).
· 워커 → UI는 시그널로만: itemStarted(id) · itemDone(id, outputPath) · itemFailed(id, reason) · jobFinished(summary). 모델 상태 전이는 UI 스레드에서만 수행(경합 방지).
· 취소: Job에 취소 플래그 → 대기 QRunnable은 시작 시 확인 후 skipped, 실행 중 항목은 완료 후 결과 폐기 + 임시파일 삭제(failed: 취소).
· 출력 절차(INV-01·02·05): OS 임시 폴더에 변환 → 성공 시 결말 위치로 원자적 이동(이름 충돌이면 이름 (1).ext 재계산) → 그때 done 전이. 원본은 읽기 전용으로만 연다.
