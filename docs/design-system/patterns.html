항목기준
키보드 완주드롭존(Enter=파일 선택) → 파일 행(포맷 셀렉트·제거) → 변환하기 → 기록. Tab 순서 = 시각 순서. 드래그 없이 모든 기능 수행 가능
포커스 표시2px primary 링, offset 2px. 포커스 링 제거 금지
클릭 타깃≥ 32×32px(데스크톱 포인터 기준) · 행 높이 ≥ 36px. 아이콘 단독 버튼(✕, 폴더, 삭제)은 접근성 이름 필수
대비텍스트 4.5:1 이상. 상태 배지 fg/bg 조합은 F-03 토큰만 사용(검증됨)
색 비의존모든 상태 = 색 + 아이콘 + 텍스트. 진행 바에도 "3 / 5 완료" 수치 병기
오류 연결실패 사유는 해당 행 인라인(스크린리더가 행 읽을 때 함께). 토스트 금지
변환 중 알림상태 변경(완료·실패)은 라이브 리전(폴라이트)으로 공지. 스피너에 "변환 중" 텍스트 병기
Esc / 단축키Esc = 다이얼로그 안전 행동 · Ctrl+O = 파일 선택 · Enter = 변환하기(포커스 무관, 목록 유효 시)
