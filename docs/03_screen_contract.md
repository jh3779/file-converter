# 03. 화면 계약 (Screen Contract)

> 인터뷰 영역 5 정리 — 화면별 "무엇을 반드시 보이고, 무엇을 할 수 있는가" · 상태: draft

## SCR-001 · 메인 (원스크린 드롭존)
- **목적:** 파일 추가 → 포맷 선택 → 변환 시작을 한 화면에서 3클릭으로 완결 (REQ-NF-006)
- **진입:** 앱 실행 / SCR-002·003에서 복귀
- **가시 의무(반드시 보여야 하는 것):**
  - 드롭존 (empty일 때 화면 대부분 차지, 파일이 있으면 상단으로 축소)
  - 추가된 파일 목록: 파일명 · 원본 포맷 · 대상 포맷 드롭다운 · 개별 제거 버튼
  - 대상 포맷 드롭다운에는 **해당 확장자에서 가능한 포맷만** 노출 (REQ-F-002)
  - 저장 위치 표시("원본 폴더") — MVP에서는 고정, 변경 불가임을 명시
  - 변환하기 버튼 (파일 0건 또는 포맷 미선택 파일 존재 시 비활성 + 사유)
  - converting 상태: 파일별 진행 표시(대기/변환 중/완료/실패) + 전체 진행률 + 취소 버튼
- **행동(사용자가 할 수 있는 것):**
  - 파일 드래그앤드롭 / 클릭해서 파일 선택 → 목록에 추가
  - 파일별 대상 포맷 선택, 파일 개별 제거, 전체 비우기
  - 변환하기 → converting 상태 → 완료 시 SCR-002
  - 변환 중 취소 → 완료분 유지, 진행분 정리 (FLOW-001)
  - 기록 아이콘 → SCR-003
- **상태별 표현:**
  | 상태 | 표현 |
  |------|------|
  | empty | 큰 드롭존 + "파일을 여기에 끌어다 놓으세요 (또는 클릭해서 선택)" 단일 안내 |
  | list | 파일 목록 + 포맷 선택 + 변환하기 버튼 |
  | converting | 파일별 상태 아이콘 + 전체 진행률, 입력 잠금(파일 추가 불가), 취소만 가능 |
  | 지원 불가 파일 | 목록에 비활성 행으로 표시 + "지원하지 않는 형식입니다" 사유 |
- **금지:** 원본 파일 수정·이동·삭제. 네트워크 요청. 변환 완료 전 성공 표시. 저장 위치 선택 UI(MVP 범위 밖).
- **근거:** REQ-F-001~008 · REQ-NF-006~008 · FLOW-001

## SCR-002 · 변환 결과 요약
- **목적:** 일괄 변환 결과를 성공/실패 건수와 사유로 요약 (REQ-F-009)
- **진입:** SCR-001 converting 완료 시 자동
- **가시 의무:**
  - 성공 N건 / 실패 M건 요약
  - 실패 파일별: 파일명 + 사람이 읽을 수 있는 실패 사유(예: "암호가 걸린 파일입니다")
  - 결과 폴더 열기 버튼 (성공 1건 이상일 때)
- **행동:**
  - 결과 폴더 열기 → OS 파일 탐색기
  - 확인 → SCR-001 복귀 (전체 성공: 목록 비움 / 실패 존재: 실패 파일만 남겨 재시도 가능)
- **상태별 표현:**
  | 상태 | 표현 |
  |------|------|
  | all-success | 성공 강조 + 폴더 열기 |
  | partial-fail | 성공·실패 병기, 실패 사유 목록 |
  | all-fail | 실패 사유 목록 + 재시도 유도 |
- **금지:** 기술 용어 그대로의 에러 메시지(스택트레이스 등) 노출.
- **근거:** REQ-F-009 · REQ-NF-008 · FLOW-001

## SCR-003 · 최근 기록
- **목적:** 최근 변환 N건에서 결과 파일을 다시 찾기 (REQ-F-010)
- **진입:** SCR-001 기록 아이콘
- **가시 의무:**
  - 기록 목록: 원본 파일명 → 대상 포맷, 변환 일시, 성공/실패
  - 기록이 로컬에만 저장됨을 알리는 한 줄 안내
- **행동:**
  - 항목 클릭 → 결과 파일 위치를 OS 탐색기로 열기 (파일이 삭제됐으면 "파일을 찾을 수 없음" 안내)
  - 개별/전체 기록 삭제 (확인 1회) — 파일은 건드리지 않고 기록만 삭제
  - 뒤로 → SCR-001
- **상태별 표현:**
  | 상태 | 표현 |
  |------|------|
  | empty | "아직 변환 기록이 없습니다" + 안내 |
  | list | 최신순 목록 |
- **금지:** 결과 파일 자체의 삭제·이동 기능(기록 관리만).
- **근거:** REQ-F-010 · REQ-NF-008 · FLOW-002
